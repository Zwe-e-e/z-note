Three steps, then make it yours.

  1. Download & extract

    Save the ZIP, then choose Extract All. Move the extracted Z Note folder anywhere you want to keep it.

  2. Open on your PC

    On Windows, double-click Z Note.exe (the blue Z icon) for Chrome or Edge with background Keep Awake and automatic app updates. Keep the extracted folder together when moving it to another PC. Opening Z Note.html directly uses visible-window Keep Awake and manual updates.

  3. Choose your source folder

    Choose a folder to create your notebook. Already have notes? Use Open existing notebook and select Z Note notebook itself or its parent folder.

Your notebook stays with you. Each person creates their own notes on their own PC. Folder access needs your browser’s permission. If you choose browser storage instead, download backups regularly from Style & data → Sync & backup.

Use your notebook on another PC. Connect each PC to the same OneDrive or shared notebook folder using Open existing notebook. Press Sync now before switching, wait for the folder service to finish, then sync on the other PC. A copied folder alone does not carry later changes.

Already using Z Note v2.4.2 or earlier? The project has moved to a new GitHub address, so one manual update is needed. Back up your notes, close Z Note, and copy the v2.5.0 update ZIP's program files into your existing app folder. Keep your notebook folder and backups; do not delete the original folder. From v2.5.0, later updates can install automatically through the Windows launcher. Read the update guide.
