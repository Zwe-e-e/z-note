Z NOTE - PORTABLE BROWSER APP
Version 2.6.3 - released 26 November 2026
Check your installed version at the bottom of the sidebar or in Style & data.
Use "Check for updates" in the sidebar or Style & data > Updates.

NEW IN 2.6.3
The icon launcher locates the app beside the actual running Z Note.exe.
Opening errors now identify missing files and access problems, with the full
application, page and Windows-helper paths. If only the helper is missing,
the launcher explains that background Keep Awake and automatic installation
are unavailable, then opens the same local page in browser mode. A present
helper still follows the normal startup route; startup and access errors do
not silently switch modes. Both the full portable ZIP and v2.6.3 automatic
update include this updated icon launcher. Notes, browser storage and this
PC's source-folder settings are kept.

IF THE Z ICON DOES NOT OPEN
Try Open Z Note.cmd from the same extracted app folder. Keep the exact error
message and full paths for diagnosis. CMD can also open browser mode when the
helper is missing, so opening through CMD alone does not confirm the helper
is working. Keep using the same app location and browser profile for your notes.
The reported failure on another PC could not be reproduced; v2.6.3 improves
path resolution and diagnostics but does not bypass Windows access restrictions.

NEW IN 2.6.2
Failed updates offer Back to my notes when the helper confirms the app was not
changed or was restored. An unconfirmed update still offers Close Z Note so
recovery can finish safely. Read-only app files stop installation with a clear
message before any app file changes. Notes and recovery backups are preserved.
Recovery validates the complete file list and all original backup files before
restoring anything. Files already restored to their original bytes are kept.
The sync permission banner includes Locate notebook on this PC: select this
PC's copy of the same notebook when the OneDrive path differs.
Board Ctrl/Command + wheel zoom now uses about 5% per mouse-wheel step instead
of 18%, with gentler trackpad zoom and smooth movement through 100%.

IF AN OLDER UPDATE WINDOW IS ALREADY STUCK
After an error appears, use the Windows title-bar X or Alt+F4 to close it, then
reopen the same Z Note.exe once for recovery. If the icon cannot open, try
Open Z Note.cmd from that same app folder and keep the exact error and paths.
An older open window cannot gain the new recovery buttons until it loads the
updated application.
If it opens, save a fresh backup from Style & data > Sync & backup. If recovery
still fails, retain the automatic JSON backup shown in the error and preserve
the old app and notebook folders for diagnosis. Do not delete update recovery
files, clear browser data, or overwrite a partly recovered app. A new app
location can have separate browser storage and needs its own folder permission.

NEW IN 2.6.1
The expense Category dropdown includes categories already used on your expense
pages, across all dates. Choose one or type a new category; blank uses Other.
Budget & expenses now has a Period selector: Monthly, Weekly, Yearly or Project.
Weeks run Monday to Sunday. Project lets you save a custom start and end date;
both dates are included in the expense list, totals and category pie chart.
Use one expense page per project and give the page your project's name.
Set a separate budget for the selected week, month, year or project date range.
Changing a project range keeps its previous budget saved for the original dates.
All expenses and receipts are kept, including those outside the selected period.
Existing pages stay monthly until you change them. The chosen mode and project
dates are remembered and included in sync/backups. Ctrl+Z can undo these changes.
Older v2.6.0 copies retain these settings but only display monthly reports;
use v2.6.1 or later on each PC for the new period controls and category suggestions.

If the app files are already updated but an old window is still open, use Reload
installed version to save your notes and load the installed app. Update errors
now provide a safe way to return to your notes or close Z Note for recovery.
Long recovery-backup paths wrap inside the dialog.
Source folder and Sync & backup show the same "Folder on this PC" panel.
Paste the selected folder's full address from File Explorer once, then use
Copy path or Copy sync instructions. For recognizable OneDrive locations, the
panel also shows where to find the notebook inside that OneDrive account.
The other PC's drive letter or user folder may differ. Open existing notebook
on that PC and select the same shared notebook; copying a path does not sync it.

GET STARTED
1. Extract the ZIP completely. Keep the whole "Z Note" folder together.
   Do not run the app from inside the ZIP preview.
2. On Windows, double-click "Z Note.exe" (the blue Z icon). It opens Z Note
   in Chrome or Edge with background Keep Awake and automatic updates.
   "Open Z Note.cmd" also works. Keep the whole extracted folder together;
   the icon launcher still works after moving that folder to another PC.
   You can also open "Z Note.html" directly in a desktop browser, with
   visible-window Keep Awake and manual updates. No installer or account is needed.
3. In the first-run setup dialog, click "Choose source folder".
4. Select the extracted "Z Note" folder (the folder containing this file),
   or another location where you want to keep your notebook.
5. Allow the browser to access that folder. Z Note creates a new
   "Z Note notebook" folder inside it for your pages and pictures.
   Already have notes on another PC? Use "Open existing notebook" instead,
   then select "Z Note notebook" itself or the folder containing it.

The app files work offline after extraction. Keep the app subfolder beside
Z Note.html. Screen capture and folder access still depend on your browser
and its permissions. Desktop Chrome or Edge is recommended for folder access.

YOUR NOTES AND BACKUPS
Your notes are stored in this browser on this device. Choosing a source folder
also keeps a file copy in "Z Note notebook". Your private notes are not included
in the public download and are not sent to the Z Note GitHub repository.

If you already have a "Z Note notebook" folder, use "Open existing notebook".
Choose that folder itself OR the folder containing it. Z Note reconnects to it.
When both places hold notes, follow the app's choices to combine or use the
folder's notebook.

If the browser asks again after reopening, click "Allow" in Z Note to resume
folder access. You can manage the folder and download or restore a backup in:
    Style & data > Sync & backup

This dialog always shows the connected notebook folder location. If the full
path is not saved, paste the selected folder's full path from File Explorer
and click Save full path. It stays visible here, with a Copy path button.
Browsers cannot discover the full path automatically. Use Edit path if you
move or rename the folder; the saved display path does not move your notes.

SOURCE FOLDER LOCATION
The bottom of the sidebar shows your source folder and "Z Note notebook".
Click it for the full details, Copy location, Locate folder, Sync now,
and Open existing notebook.
Browsers hide the complete Windows path. To display it, paste the selected
folder's path from File Explorer into "Selected folder's full path".
This optional label stays in this browser; it does not move your notes or
change the folder connection.

"Use browser storage" lets you start without a folder. Browser storage does
not travel with the app folder, and clearing site data can erase it. Download
backups regularly. If storage is blocked, the app offers a temporary session;
download a backup before closing it.

MOVING TO ANOTHER COMPUTER
Open Z Note on the other PC and choose "Open existing notebook" in setup,
Source folder, or Style & data > Sync & backup. Select "Z Note notebook"
itself or its parent. Allow folder access in the browser on each PC.

For changes to travel between PCs, use the same notebook in OneDrive,
another desktop sync service, or a shared network folder:
1. On the first PC, press "Sync now" in Source folder or Sync & backup.
2. Wait for OneDrive or your folder service to finish uploading.
3. On the other PC, wait for the files to finish downloading, then press
   "Sync now" in Z Note to load the changes.

Work on one PC at a time. Concurrent changes to the same page can overwrite
each other: the newer change wins. A one-time folder copy moves your notes
but does not carry later changes between PCs.

You can also download a backup on the old computer and restore it through
Style & data > Sync & backup on the new computer. Browser storage and folder
permissions are separate on each PC; they do not travel with the app folder.

SHARING AND UPDATING
Share the original "Z-Note-Portable.zip" download with other people. Each
person creates their own notebook. Do not share your working folder or your
"Z Note notebook" folder unless you intend to share its private contents.

Click "Check for updates" to compare your version with the latest stable
GitHub release. Internet access is needed only for the check and download.
If the check fails, retry later or use the official releases page. Your notes,
pictures and source-folder path are not sent to GitHub.

ONE-TIME UPDATE FROM v2.4.2 OR EARLIER
Z Note has moved to Zwe-e-e/z-note on GitHub. Already-installed older versions
cannot install from the new address automatically. Download the update ZIP:
https://github.com/Zwe-e-e/z-note/releases/download/v2.5.0/Z-Note-v2.5.0-Portable.zip

1. Save a backup from Style & data > Sync & backup. Confirm the JSON file
   has finished saving before continuing.
2. Close all Z Note windows and extract the update ZIP into a separate folder.
3. Copy the application files from its "Z Note" folder into your original
   Z Note app folder, replacing matching program files. Keep "Z Note notebook"
   and all backups. Do not delete your original folder.
4. Reopen through your existing shortcut or "Open Z Note.cmd", using the same
   folder and browser profile. Check your notes and source-folder settings.

The update ZIP keeps the existing launcher. The full portable download adds
the new "Z Note.exe" icon launcher and is the usual choice for a new installation.
Use the new download page: https://zwe-e-e.github.io/z-note/
The old GitHub Pages address does not redirect to the new page.

AUTOMATIC UPDATES ON WINDOWS FROM v2.5.0
Open "Z Note.exe" or "Open Z Note.cmd". Later releases from the new repository
can use "Check for updates" > "Install update automatically". Close other
Z Note windows and keep this window open while it works. Z Note saves a recovery
backup, shows its path, verifies the download and updates the application files
in place. Notes, pictures, source-folder settings and display settings are kept.

The v2.6.3 automatic update also installs the updated Z Note.exe icon launcher.
It contains the same complete application files as the full portable download.
For direct HTML use, save a backup and use the manual copy steps above with
the full v2.6.3 ZIP, keeping the original app location, notebook and backups.

Keep the recovery backup until you have checked your notes. If the update
result cannot be confirmed, follow the instruction to close and reopen the
launcher so recovery can finish. The manual copy steps above also work when
opening the HTML directly or when the launcher is unavailable.

Keep the same app location and browser profile to retain notes and folder
settings. If you choose a new app location, use "Open existing notebook"
and select "Z Note notebook" itself or its parent. If your notes were kept
only in browser storage, restore your JSON backup through Style & data >
Sync & backup > Restore from a file, then choose "Add to my notebook".
Copying the app does not copy browser data.

For the hosted web app, save a backup first, then refresh the page in the same
browser profile. The hosted and downloaded apps use separate browser storage;
reconnect the notebook folder or restore your backup when moving between them.

KEEP AWAKE
On Windows, open "Z Note.exe", then click "Keep Awake" beside "Snip".
"Awake on" keeps the display and computer awake even when Z Note is minimized
or covered by another app. Click it again to stop. Closing or reloading the
Z Note window releases it; it starts off each time you reopen the app.
Manual sleep, locking, lid-close actions and Windows policy still apply.

The launcher uses app/native/ZNoteHost.exe, a small Windows helper included
in the download. It uses the .NET Framework included with Windows 10/11.
Keep the entire app folder together. It does not change your power settings.

If you open the HTML directly or use the hosted website, the button shows
"Awake: visible" and pauses when hidden. Download the latest ZIP and open
"Z Note.exe" (or "Open Z Note.cmd") to use background Keep Awake. If the helper disconnects,
reopen using the launcher.
